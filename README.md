# massives-v-C-
Массивы и указатели в языке программирования C

Данный репозиторий содержит решения двух заданий по теме «Массивы и указатели в языке программирования C».

## Требования

- Компилятор C с поддержкой стандарта C11 (или более нового).
- Для `task2.c` обязательна поддержка массивов переменной длины (VLA). GCC и Clang поддерживают её при использовании `-std=c11`.
- Рекомендуется компилировать с включёнными предупреждениями.

## Компиляция

### task1.c

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic -O0 task1.c -o task1
gcc -std=c11 -Wall -Wextra -Wpedantic -O0 task2.c -o task2
